O(1) Evaluation Speedup

Replaced massive 1.2M × 451 matrix multiplications with precomputed 2-hop index lookups. s2 = adj @ adj is computed once per time step (O(N³)), then all pair features use direct index access s2[i,j] in O(1). Reduces eval time by orders of magnitude.

Exact Zero-Overlap Lag

first_lag = (2 × target_w) // 5 ensures the source-scale observation window at lag k predates the target-scale prediction window by at least 2 full target windows. Eliminates any temporal information leakage between features and labels.

F2-Aligned Thresholding

Instead of default 0.5, the pipeline scans the full precision-recall curve on calibration scores to find the threshold maximising F2 = 5·P·R / (4P + R). Calibration (Platt/Isotonic) is fit on a separate holdout before threshold search, ensuring no test-set contamination.

Logloss Early Stopping

AUC is monotonically non-decreasing during GBDT training, causing early stopping to never trigger (always timeouts at 2000 iterations). Switched to binary_logloss which decreases reliably. AUC and F2 are tracked as reference curves only, not for stopping decisions.

Native Class Imbalance Handling

LightGBM's is_unbalance=True automatically adjusts sample weights for binary classification. Combined with 1:1 negative ratio sampling during training (all positives kept, negatives downsampled to match), this handles the extreme class imbalance in adjacency matrices without manual tuning.

Ablation Study Design

Two variants per fold: Full (all features) vs Pure Cross-Scale (target-scale features removed via startswith filter). If Pure Cross-Scale matches or exceeds Full, it proves multi-scale topological transfer carries genuine non-redundant signal beyond target-scale auto-correlation. The startswith filter prevents substring collision (e.g., w35 features when target_w=135).

// Prerequisites & Setup
Required
🐍 Python ≥ 3.9
⚡ lightgbm ≥ 4.0
🔧 scikit-learn ≥ 1.3
⭐ shap ≥ 0.43
Notes
SHAP and matplotlib are optional — the pipeline runs without them but skips SHAP summary plots and all diagnostic visualisations respectively. joblib is required for multi-fold parallelism. The parameters.py module and extract_distance_matrices.py (providing SP500_TICKERS_457 and reorder_by_gics) must be importable from the working directory.
1
Install dependencies
$ pip install lightgbm scikit-learn numpy matplotlib shap joblib
2
Prepare PKL directory
Ensure the PKL files exist at the expected path (default shown below), or pass --pkldir to override:
DEFAULT_PKL_DIR = "../Quasi_Differentiation_High_Temporal_Resolution_Cross_Correlations/Codes/Extract distance matrix (2017-2022) from pkl file"

# Expected files:
# IQDw35.pkl IQDw70.pkl IQDw120.pkl IQDw180.pkl
3
Run training
Minimal — single source→target scale
$ python train_cross_scale.py \
  --source_ws 35 \
  --target_w 70 \
  --save_dir ./output_w35_to_w70 \
  --save_plots
Full — with ablation and parallel folds
$ python train_cross_scale.py \
  --source_ws 35 \
  --target_w 70 \
  --do_ablation \
  --parallel_folds 4 \
  --gbdt_n_jobs -1 \
  --save_plots \
  --shap_max_samples 5000
4
Additional CLI flags
reference
--neg_ratio 1 # neg:pos sampling ratio (default 1)
--history_lags 1 # number of lagged snapshots
--n_folds 0 # 0 = auto-compute max folds
--min_calib_steps 12 # calibration holdout (weeks)
--min_test_steps 12 # test holdout (weeks)
--max_window_size 120 # max rolling train window (weeks)
--calibration auto # auto | platt | isotonic | none
--eval_tail_frac 0.2 # fraction of train for early stopping
--seed 42 # master RNG seed
⚠  Memory: Full evaluation uses all 104,016 pairs per time step per fold. For large target windows with many folds, peak RAM can exceed 32 GB. Reduce --max_window_size or use fewer folds if memory-constrained.
